# AIDS Database Schema

## 1. Students
- RegisterNo (PK, String)
- Name (String)
- Batch (String)
- Section (String)
- Email (String)
- Phone (String)
- Gender (String)
- Department (String)
- Semester (Integer)
- Status (String: ACTIVE, INACTIVE)
- CreatedAt (Timestamp)
- UpdatedAt (Timestamp)

## 2. AccessKeys
- RegisterNo (PK, String)
- SecretKeyHash (String)
- Role (String: STUDENT, STAFF)
- Status (String: ACTIVE, BLOCKED)
- LastLogin (Timestamp)
- CreatedAt (Timestamp)
- UpdatedAt (Timestamp)

## 3. Fees
- FeeID (PK, String)
- RegisterNo (String)
- AcademicYear (String)
- Semester (Integer)
- FeeType (String)
- TotalAmount (Decimal)
- DueDate (Date)
- Status (String)
- CreatedAt (Timestamp)
- UpdatedAt (Timestamp)

## 4. Payments
- PaymentID (PK, String)
- FeeID (String)
- RegisterNo (String)
- Amount (Decimal)
- PaymentDate (Date)
- PaymentMode (String)
- TransactionReference (String)
- RecordedBy (String)
- CreatedAt (Timestamp)

## 5. Hostel
- RegisterNo (PK, String)
- AccommodationType (String: Hosteller, Day Scholar)
- HostelName (String)
- RoomNumber (String)
- HostelFee (Decimal)
- MessFee (Decimal)
- Status (String)
- UpdatedAt (Timestamp)

## 6. Transport
- RegisterNo (PK, String)
- UsesCollegeBus (Boolean)
- Route (String)
- BusNumber (String)
- TransportFee (Decimal)
- Status (String)
- UpdatedAt (Timestamp)

## 7. Academics
- AcademicID (PK, String)
- RegisterNo (String)
- AcademicYear (String)
- Semester (Integer)
- SGPA (Decimal)
- CGPA (Decimal)
- Backlogs (Integer)
- AcademicRemarks (String)
- AcademicStatus (String)
- UpdatedAt (Timestamp)

## 8. Achievements
- AchievementID (PK, String)
- RegisterNo (String)
- Category (String)
- EventName (String)
- Organizer (String)
- EventDate (Date)
- Level (String)
- Position (String)
- Description (String)
- ProofReference (String)
- VerificationStatus (String: PENDING, VERIFIED, REJECTED)
- VerifiedBy (String)
- VerifiedAt (Timestamp)
- CreatedAt (Timestamp)
- UpdatedAt (Timestamp)

## 9. Certifications
- CertificationID (PK, String)
- RegisterNo (String)
- CourseName (String)
- Platform (String)
- CompletionDate (Date)
- Score (String)
- CertificateURL (String)
- ProofReference (String)
- VerificationStatus (String: PENDING, VERIFIED, REJECTED)
- VerifiedBy (String)
- VerifiedAt (Timestamp)
- CreatedAt (Timestamp)

## 10. Activities
- ActivityID (PK, String)
- RegisterNo (String)
- ActivityName (String)
- Date (Date)
- Role (String)
- Description (String)

## 11. Staff
- StaffID (PK, String)
- Name (String)
- Email (String)
- Phone (String)
- Role (String)
- Department (String)

## 12. AuditLog
- LogID (PK, String)
- Timestamp (Timestamp)
- UserID (String)
- Role (String)
- Action (String)
- Module (String)
- RecordID (String)
- RegisterNo (String)
- OldValue (String)
- NewValue (String)
- Result (String)
- Remarks (String)

## 13. Settings
- SettingKey (PK, String)
- SettingValue (String)
- Description (String)
